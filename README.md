# Card｜公司卡報帳整理

單一 HTML 頁面的公司卡報帳工具，針對卡號尾碼 `2388`：

- 極簡操作介面，辨識設定、排除項目、進階欄位與注意事項預設收合
- 台幣與原幣金額同時顯示，方便快速辨認海外消費
- 從帳單圖片辨識消費明細
- 排除現金回饋與國外交易手續費
- 勾選已找到收據的消費，並在表格以顏色提示
- 一次拖入多個收據，依店家、日期、金額與幣別自動配對
- 顯示自動配對信心與理由，低信心結果可在複查區改選
- 以紫色「實體」標記區分紙本發票
- 在頁面最下方按「生成信件」，產生可複製的實體發票通知
- 為每筆消費加入 JPG、PNG、WEBP 或 PDF 附件
- 在下方複查區預覽附件與匯出檔名
- 自動偵測 GoDaddy、Adobe、ChatGPT、Helium 10 等訂閱店家並顯示安全的發票入口
- 綠色按鈕獨立下載 Excel；發票 ZIP 只包含重新命名的附件

附件命名格式：

```text
消費日期_商店說明_金額幣別.副檔名
```

例如：

```text
2026-06-03_SAMPLE_HOTEL_TOKYO_18000JPY.jpg
2026-06-01_範例文具行_1200TWD.pdf
```

若該筆有填寫備註，檔名會使用備註取代商店說明。若該筆有原幣金額，檔名優先使用原幣金額與幣別；否則使用台幣金額與 `TWD`。

## 使用方式

1. 下載 `index.html` 後，用瀏覽器開啟。
2. 拖入信用卡帳單圖片並確認辨識結果。
3. 需要調整年度或查看辨識規則時，再展開「辨識設定與隱私」。
4. 把所有收據一次拖進「附件複查區」；程式會讀取文字並自動配對。
5. 確認低信心或未配對的附件，必要時直接從附件卡片改選消費。
6. 若持有紙本發票，在表格的「實體」欄勾選，該列會顯示紫色標記。
7. 原幣幣別與金額會直接顯示；入帳日可從表格右上角的「更多」開啟。
8. 到頁面最下方按「生成信件」，確認文字後按「複製信件」，即可貼到 Email、LINE 或公司通訊軟體。
9. 帳單出現已知訂閱服務時，可從「這些可能是訂閱」直接前往找發票。
10. 按綠色「下載 Excel」取得清單；按「下載發票 ZIP」取得純附件壓縮檔。

## 隱私

帳單辨識、附件配對與 ZIP 打包都在瀏覽器本機完成。頁面只會從公開 CDN 載入 Tesseract.js、PDF.js、SheetJS 與 JSZip，不會把帳單或收據上傳到伺服器。

基於瀏覽器安全限制，附件只保留在目前頁面工作階段；完成夾檔後請先匯出，再關閉或重新整理頁面。
