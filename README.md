# Card｜公司卡報帳整理

單一 HTML 頁面的公司卡報帳工具，針對卡號尾碼 `2388`：

- 從帳單圖片辨識消費明細
- 排除現金回饋與國外交易手續費
- 勾選已找到收據的消費，並在表格加上刪除線
- 為每筆消費加入 JPG、PNG、WEBP 或 PDF 附件
- 在下方複查區預覽附件與匯出檔名
- 匯出一個 ZIP，內含 Excel 與所有重新命名的附件

附件命名格式：

```text
消費日期_商店說明_金額幣別.副檔名
```

例如：

```text
2026-06-03_SAMPLE_HOTEL_TOKYO_18000JPY.jpg
2026-06-01_範例文具行_1200TWD.pdf
```

若該筆有原幣金額，檔名優先使用原幣金額與幣別；否則使用台幣金額與 `TWD`。

## 使用方式

1. 下載 `index.html` 後，用瀏覽器開啟。
2. 拖入信用卡帳單圖片並確認辨識結果。
3. 在每筆消費右側按迴紋針，或在「附件複查區」選擇消費後拖入收據。
4. 確認複查區顯示的預覽與新檔名。
5. 按「匯出整理包」，下載包含 Excel 與附件的 ZIP。

## 隱私

帳單辨識、附件配對與 ZIP 打包都在瀏覽器本機完成。頁面只會從公開 CDN 載入 Tesseract.js、SheetJS 與 JSZip，不會把帳單或收據上傳到伺服器。

基於瀏覽器安全限制，附件只保留在目前頁面工作階段；完成夾檔後請先匯出，再關閉或重新整理頁面。
