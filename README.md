# Card｜公司卡報帳整理

單一 HTML 頁面的公司卡報帳工具，支援卡號尾碼 `2388` 與 `7802`：

- 右上角切換報帳卡片；同一份帳單只需辨識一次，即可分別整理兩張卡
- 每張卡分開保留消費、備註、發票勾選與附件；Excel、ZIP 與摘要使用目前選取的卡號
- 極簡操作介面，辨識設定、排除項目、進階欄位與注意事項預設收合
- 台幣與原幣金額同時顯示，方便快速辨認海外消費
- 從帳單圖片或 PDF（含掃描型 PDF）辨識消費明細
- 掃描 PDF 以高解析度分段辨識，重疊區只計算一次；即使左側日期欄裁掉，也可依金額與卡號尾碼擷取交易
- 排除現金回饋與國外交易手續費
- 勾選已找到收據的消費，並在表格以顏色提示
- 一次拖入多個收據，只有證據充分且唯一的候選才自動配對；同分、接近、競爭同一筆或幣別衝突保留待確認
- 顯示自動配對信心與理由，低信心結果可在複查區改選
- 以紫色「實體」標記區分紙本發票
- 在頁面最下方產生「本期報帳通知」或「實體發票通知」，可編輯主旨／正文、複製或下載 `.eml` 草稿，不自動寄送
- 為每筆消費加入 JPG、PNG、WEBP 或 PDF 附件
- 在下方複查區預覽附件與匯出檔名
- 依本期店家顯示收據／發票入口，包含訂閱、展會與住宿等消費；MB／Mandalay 展商服務可直接開啟官方訂單入口
- 綠色按鈕獨立下載 Excel；發票 ZIP 只包含重新命名的附件

附件命名格式：

```text
消費日期_商店說明_金額幣別.副檔名
```

例如：

```text
2026-06-03_SAMPLE_HOTEL_TOKYO_18000JPY.jpg
2026-06-01_範例文具行_1200TWD.pdf
```

若該筆有填寫備註，檔名會使用備註取代商店說明。若該筆有原幣金額，檔名優先使用原幣金額與幣別；否則使用台幣金額與 `TWD`。

## 使用方式

1. 下載 `index.html` 後，用瀏覽器開啟。
2. 右上角選擇尾號 `2388` 或 `7802`，拖入信用卡帳單圖片或 PDF，按「開始辨識」並確認結果；多頁 PDF 會在瀏覽器本機逐頁辨識。
3. 需要調整年度或查看辨識規則時，再展開「辨識設定與隱私」。
4. 把所有收據一次拖進「附件複查區」；程式會讀取文字並自動配對。
   - 首次圖片辨識需要載入中英日文資料，畫面會顯示目前份數、載入階段與百分比。
   - 不想等待可按「停止辨識，改手動配對」；單份讀取超過 90 秒也會停止本批後續辨識並保留全部原檔，不必重新上傳。
   - 原始附件放入後立即開始本機保存，不必等辨識完成；讀取失敗、停止或逾時不會自動勾選未辨識的附件。
5. 確認低信心或未配對的附件，必要時直接從附件卡片改選消費。
6. 若持有紙本發票，在表格的「實體」欄勾選，該列會顯示紫色標記。
7. 原幣幣別與金額會直接顯示；入帳日可從表格右上角的「更多」開啟。
8. 到頁面最下方「報帳信件」選擇「本期報帳通知」或「實體發票通知」，按「生成信件」。本期通知包含目前卡片全部明細、總額、備註、憑證狀態與附件清單，不受列表搜尋或篩選影響；只有勾選找到但未夾檔／標記實體，仍列為缺少憑證。可修改主旨與正文，再複製或下載 `.eml` 草稿。
   - 草稿只保存在此瀏覽器，不自動寄送，也不含附件。請另行夾入 Excel／發票 ZIP，確認收件人與內容後再寄出；不同郵件程式開啟 `.eml` 的方式可能不同，也可直接複製文字。
   - 修改明細、配對或信件模式後，保留舊稿文字並提示過期，重新生成前不能複製或下載。重新生成會取代自訂文字，請先自行保留需要的部分。
9. 帳單出現已知店家時，可從「收據／發票入口」查看查找方式及官方連結，不限訂閱服務。MB 展商服務請在 My Orders 選訂單，開 Print Receipt 並核對 Payment History 的本次付款，不使用整單金額代替單次扣款，也不與 MBAY FRONT DESK 住宿費混用。
10. 按綠色「下載 Excel」取得清單；按「下載發票 ZIP」取得純附件壓縮檔。
11. 切換到另一張卡繼續整理與匯出。切回前一張卡時，已修改的備註、勾選與本頁附件都會保留；辨識、附件配對或匯出進行中暫停切換。

若帳單缺少日期，消費日期會保留空白並以淡黃色提示，請根據完整帳單核對補齊。程式不會替缺失日期填入推測值。

## 整理進度

每份帳單依卡號各自保留本機整理進度。尾號 `2388` 的舊版進度仍可載入；新版另存新格式，不會改寫舊版儲存內容。切換卡片會沿用同份帳單的辨識原文，不重新執行 OCR。

完整進度（原始帳單、兩張卡的修改、收據原檔與配對、每卡信件草稿）會存入此瀏覽器的 IndexedDB，重開會還原最後一份帳單；重選之前的原始帳單可取回該份已保存的完整進度。新放入的帳單和附件會立即開始寫入，不必等辨識完成；尚未辨識的帳單重開會提示「等待開始辨識」。請等上方「已保存」再重新整理或關閉頁面。保存失敗不會清空畫面，會持續警告並提醒離頁；另一分頁已更新時也不會靜默覆蓋。

檔案誤拖到兩個上傳區之外時，不會開啟檔案而離開 Card，會提示放入正確區域；不會猜測是帳單還是收據，也不會自動加入。

「下載完整備份」包含兩張卡的收據、原始帳單及 `整理進度.json`，可人工復原；目前不提供一鍵匯入備份。「清除本期本機資料」確認後只刪除目前帳單兩張卡的本機副本，畫面仍保留，繼續編輯會重新保存。清除瀏覽器資料、無痕模式或瀏覽器儲存空間回收都可能移除本機副本，因此仍應定期下載備份。

舊版只保存文字，不含附件，無法憑空還原；載入時會提醒已勾找到但未夾檔／未標記實體的項目。再次辨識失敗或解析零筆時保留原整理結果，不會清空已核對資料。ZIP 命名會避免大小寫與序號碰撞，保留全部附件。

## 隱私

帳單辨識、附件配對與 ZIP 打包都在瀏覽器本機完成。頁面只會從公開 CDN 載入 Tesseract.js、PDF.js、SheetJS 與 JSZip，不會把帳單或收據上傳到伺服器。

本機保存不等於雲端同步或加密保險箱；同一瀏覽器使用者與同來源網站程式可存取，請只在受信任的個人裝置使用。示範模式使用獨立資料庫，與真實帳單分開。
